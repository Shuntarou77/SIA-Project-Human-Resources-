## Local Setup

Since sensitive configuration files are excluded from the repository for security, you need to set them up manually after cloning:

1.  **Rename Example Files**:
    *   Navigate to the `ExWebAppSia` folder.
    *   Copy `appSettings.config.example` and rename it to `appSettings.config`.
    *   Copy `connectionStrings.config.example` and rename it to `connectionStrings.config`.

2.  **Configure Credentials**:
    *   Open `appSettings.config` and provide your SMTP details (Gmail App Password, etc.).
    *   Open `connectionStrings.config` and update the `MongoDBConnection` string with your database credentials.

3.  **Ensure Web.config References Them**:
    *   The `Web.config` is already configured to look for these files externally via the `configSource` attribute.

```xml
<appSettings configSource="appSettings.config" />
<connectionStrings configSource="connectionStrings.config" />
```
